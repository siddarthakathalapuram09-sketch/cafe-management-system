An interactive Python CLI application designed for simplified cafe order processing, bill
calculation, and payment selection.
## Features
- **Interactive Menu Display**: Shows available items alongside prices.
- **Dynamic Billing**: Uses Python dictionary key-value lookup to sum total costs.
- **Multi-Item Support**: Prompts the user for additional items before finalizing the order.
- **Multiple Payment Options**: Supports Cash, UPI, and Card transactions.
